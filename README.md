# Johanns Wunscherfüller

Kleine Web-App für Johann: Stunden in Papas Brennerei eintragen, Guthaben sehen und auf Wünsche sparen.

**App:** https://harzeredlebrand-cell.github.io/wunscherfueller/

- Die Einträge bleiben nur auf dem Handy, auf dem die App läuft (Browser-Speicher). In diesem Repository liegen keine persönlichen Daten.
- Läuft auch offline und lässt sich als App auf den Home-Bildschirm legen.
